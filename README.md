# Git and GitHub Capstone Project

This repository contains the deliverables for the **Introduction to Git and GitHub** capstone project.

## Project Contents

- **LICENSE** — Apache License 2.0
- **CODE_OF_CONDUCT.md** — Contributor Covenant Code of Conduct
- **CONTRIBUTING.md** — Contribution guidelines
- **simple-interest.sh** — A Bash script that calculates simple interest based on user-provided principal, rate of interest, and time period

## About

This project was created to demonstrate core Git and GitHub skills, including repository setup, licensing, community health files, branching, merging, forking, and pull requests.

## Usage

Clone the repository and run the simple interest calculator:

```bash
git clone https://github.com/<your-username>/git-github-capstone.git
cd git-github-capstone
chmod +x simple-interest.sh
./simple-interest.sh
```
